# Рекомендательная система на основе кастомной user2user коллаборативной фильтрации
* Задача: изучить принципы работы рекомендательных систем, получить рекомендации и 
измерить их качество на основе датасета MovieLens
* Реализация: написал код для вычисления пользовательских similarity (косинусная мера), 
предсказания рейтингов и формирования топ-N рекомендаций. Для оценки использовал 
метрики качества ранжирования MAP@10 и NDCG@10. 
* Результат: разработанная система стабильно формирует персонализированные 
рекомендации, которые по метрикам качественно превосходят бейзлайн.
